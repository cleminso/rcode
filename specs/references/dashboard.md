## Problem Statement

Users need a view to visualize (list or card grid) their data:

- Which rooms have I created?
- Which rooms have I joined?
- Which rooms are active?
- Who else has been there?

Without durable participant/connection records, the dashboard can only show rooms user own, not rooms user joined via link.

## Solution

Dashboard access is derived from:

- Creator relationship
- Non-deleted room participant relationship
