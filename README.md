## rcode - Code Editor

A web collaborative code editor build with [Jazz](https://github.com/garden-co/jazz).

Create a code room, share the link, and collaborate instantly in real-time.

## Goal

1. Make my hands with Jazz v2 and learn the new concepts
2. Document the codebase
3. Reproduce [Avelin](https://github.com/avelinapp/avelin) App model with Jazz
4. 2-3 weeks sprint to build parity

## Out of scope

1. Implement full editor features (syntax highlighting, autocomplete, etc.) into Jazz.
